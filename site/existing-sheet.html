Using a sheet you already have

Back to setup

Usually quicker: create a new team sheet on the setup page and paste your roster into it. Your old sheet stays exactly as it is. Only follow this guide if your current sheet has history you want to keep in one file.

The field view reads one fixed layout. If a tab does not match, the team link shows an error that names the tab and what is missing, so you can fix it and reload. You need edit access to the sheet, because connecting it adds a Team Config tab.

1. One tab per game

Name each game tab so it ends with Lineup, like Game 3 Lineup. Players see every tab that matches. A tab whose name starts with OLD is hidden, which is how you retire a game. Tabs like Roster, Comments and anything else are never shown to players.

2. Game details at the top

Put these labels in column A, with the value in column B of the same row. The order and the number of rows between them do not matter.

Column AColumn B
Date:A real date, like 10/21/26. It decides which games count as played.
Time:7:00 PM
Location:Riverside Field 2
Opponent:The Dirt Sliders
Notes:Anything for the team. After the game, a result like W, 12-4 shows as Won.

3. The lineup grid

  • A header row with Name in column A and the inning numbers (1, 2, 3 and so on) starting in column C. Column B is for the kicking order.
  • One row per player below it: the name in column A, and a position in each inning column.
  • A row with Acceptable in column A below the last player. It marks the end of the grid.

Positions must be one of: P, C, 1B, 2B, 3B, SS, LF, LC, CF, RC, RF. Leave an inning blank when a player sits out. The page flags any position that is open, doubled up, or not on this list.

4. Who is playing

Pick one way and use it on every tab:

  • Kick numbers: put the kicking order (1, 2, 3 and so on) in column B. A player with a blank column B is not attending.
  • Strikethrough: with no kick numbers on the tab, a player whose name is struck through is not attending.

5. Connect it

  1. On the setup page, sign in with Google.
  2. Enter your team name and season.
  3. Open Already have a lineup sheet?, press Use a sheet I already have and pick your sheet.

The app adds a Team Config tab for the page heading, colors and suggestion box, and puts your team link on it. Nothing else in your sheet is changed.

The layout above is exactly what the team sheet template creates, so it is the best reference if something does not line up.
